# {{name}}

A terminal app built with [Svelte](https://svelte.dev) and [mudui](https://www.npmjs.com/package/mudui).

```sh
bun run dev     # run, restarting on changes
bun start       # run
bun test        # test

bun run build:linux     # single executables in dist/
bun run build:windows
bun run build:darwin    # Apple Silicon; `bun run build:darwin x64` for Intel
```

Edit `src/App.svelte` to get started.
