# create-mudui

Creates a terminal app with [Svelte](https://svelte.dev) and [mudui](https://www.npmjs.com/package/mudui).

```sh
bun create mudui my-app
cd my-app
bun run dev
```

Options:

- `--no-install`: skip `bun install`
- `--mudui <spec>`: the mudui version or specifier to depend on

The project contains one component (`src/App.svelte`), its entry point, a test, and the config needed to compile Svelte for the terminal. Nothing else.
